# Library Management System

## Overview
A simple **CLI-based Library Management System** developed using Java and OOP concepts. The system manages books and users and provides book issue and return functionality.

## Features
- Add books
- Add users
- View books and users
- Issue books to users
- Return books
- Menu-driven console interface

## Technologies Used
- Java
- VS Code
- ArrayList
- Scanner

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Getters and Setters
- Composition
- ArrayList

## Project Structure

```text
LibraryManagementSystem/
├── Book.java
├── User.java
├── Library.java
└── Main.java
```

## How to Run

Compile:

```bash
javac Book.java User.java Library.java Main.java
```

Run:

```bash
java Main
```
